🎯 Pyxel Sales Managers

Gestión Completa de Gestores de Ventas para Odoo 17

v17.0.1.0.0 Community & Enterprise LGPL-3

📋 Descripción

Pyxel Sales Managers es un módulo completo para la gestión de gestores de ventas en Odoo 17. Permite registrar, organizar y analizar el desempeño de los gestores de ventas con integración completa en los módulos de Contactos, Ventas y Facturación.

✨ Características Principales

👤 Gestión de Gestores

  • Registro completo de información
  • Código único autogenerado
  • Tasa de comisión configurable
  • Jerarquía de gestores

📞 Integración Contactos

  • Gestor principal por contacto
  • Múltiples gestores asignados
  • Estadísticas integradas
  • Búsqueda avanzada

💰 Integración Ventas

  • Campo de gestor en órdenes
  • Cálculo automático de comisiones
  • Asignación automática
  • Análisis por gestor

📊 Reportes y Análisis

  • Reporte de análisis completo
  • Vistas gráficas y pivot
  • Métricas de rendimiento
  • Filtros personalizables

🔧 Funcionalidades Detalladas

1. Gestión de Gestores de Ventas

  • Registro completo de información del gestor
  • Código único autogenerado (formato: SM00001, SM00002, etc.)
  • Tasa de comisión configurable por gestor (0-100%)
  • Jerarquía de gestores (definición de gestor superior)
  • Relación con usuarios de Odoo
  • Asignación de clientes específicos a cada gestor
  • Integración con equipos de ventas y CRM
  • Control de fechas de inicio y fin
  • Sistema de seguimiento (chatter) integrado

2. Integración con Contactos

  • Campo de gestor de ventas principal en contactos
  • Posibilidad de asignar múltiples gestores por contacto
  • Vista de estadísticas de gestores en la ficha del contacto
  • Búsqueda y filtrado por gestor en el listado de contactos
  • Agrupación de contactos por gestor de ventas

3. Integración con Ventas

  • Campo de gestor de ventas en órdenes de venta
  • Cálculo automático de comisiones basado en la tasa del gestor
  • Asignación automática del gestor desde el cliente (configurable)
  • Vista de comisión en la orden de venta
  • Análisis de ventas agrupado por gestor
  • Filtros y búsquedas por gestor en órdenes

4. Integración con Facturación

  • Campo de gestor en facturas de cliente
  • Cálculo de comisiones en facturas
  • Herencia automática del gestor en notas de crédito
  • Análisis de facturación por gestor
  • Filtros y agrupaciones disponibles

5. Reportes y Análisis

  • Reporte de análisis de gestores con múltiples vistas
  • Vista de tabla con totales y subtotales
  • Gráficos de barras para comparativas visuales
  • Tabla dinámica (pivot) para análisis multidimensional
  • Métricas: total ventas, facturado, comisiones, órdenes, facturas
  • Filtrado por fechas, gestores, equipos y clientes
  • Agrupación flexible por múltiples dimensiones

6. Configuración

  • Panel de configuración en Ajustes > Ventas
  • Opción de asignación automática de gestor
  • Hacer gestor requerido en órdenes de venta
  • Habilitar/deshabilitar jerarquía de gestores
  • Configurar tasa de comisión por defecto

7. Seguridad

  • Sistema de permisos por roles (Usuario, Gestor, Administrador)
  • Reglas de acceso a nivel de registro
  • Soporte multi-compañía
  • Control granular de permisos (lectura, escritura, creación, eliminación)

📦 Instalación

  1. Copiar el módulo en la carpeta addons de Odoo
  2. Actualizar la lista de aplicaciones
  3. Buscar "Pyxel Sales Managers"
  4. Hacer clic en "Instalar"

⚙️ Configuración Inicial

  1. Ir a Ventas > Configuración > Ajustes
  2. Buscar la sección "Gestores de Ventas"
  3. Configurar según necesidades:
    • ✓ Asignación automática de gestor
    • ✓ Hacer gestor requerido
    • ✓ Habilitar jerarquía
    • ✓ Tasa de comisión por defecto
  4. Guardar cambios

🚀 Uso Rápido

Crear un Gestor de Ventas

Ventas > Gestores de Ventas > Gestores

  1. Hacer clic en "Crear"
  2. Ingresar nombre y seleccionar contacto
  3. Definir tasa de comisión
  4. Asignar equipo de ventas y gestor superior (opcional)
  5. Agregar clientes en la pestaña "Clientes Asignados"
  6. Guardar

Asignar Gestor a un Cliente

Contactos

  1. Abrir contacto cliente
  2. Ir a pestaña "Ventas y Compras"
  3. Seleccionar "Gestor de Ventas Principal"
  4. Opcionalmente agregar gestores adicionales
  5. Guardar

Ver Reportes

Ventas > Gestores de Ventas > Análisis de Gestores

  1. Seleccionar vista (Gráfico, Pivot o Lista)
  2. Aplicar filtros por fecha, gestor, etc.
  3. Analizar métricas de rendimiento
